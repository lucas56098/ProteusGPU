# AI Usage

PROTEUS was developed with the help of AI coding tools, which for transparency are
fully disclosed here. This file does not make any statement about papers/thesis written 
related to PROTEUS, so please refer to the individual acknowledgements there.

The **Claude Opus** models (4.6 - 5.5) of **[Anthropic](https://claude.com/claude-code)** 
(VS Code / CLI extension) were used in agentic mode throughout the codebase, with every commit 
being manually audited, refined and approved by the author. During this the AI was mainly 
used to complete clearly specified tasks and did not replace any careful or critical thinking 
for scientific quality. The author takes full responsibility of the software as given in the LICENSE.

Since 28.09.2026 the entire claude history for the respective folders is 
being stored and available upon reasonable request (e.g. review process).

On a personal note: As authorship also means taking direct responsibility, i strongly believe 
that a disclosure of AI usage is the correct model rather than Co-authorship of the repository. 
In a similar fashion compiler, libraries and further tools are not an author of this 
repository even though they are essential for this software to work.

To ensure correctness beyond the manual approval, the project has its own test suites 
(e.g. compile matrix, convergence tests, bitwise reproducibility checks) which are run
regularly between commits.
